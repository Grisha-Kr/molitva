# Молитвенный дневник

Веб-приложение для записи молитвенных нужд. Разделы изображены камнями разных цветов, внутри них нужды с фото, описанием, личными записями молитв и файлами. На главной стих, который вы держите перед глазами, и отметки дней молитвы за неделю. Работает в браузере на телефоне и ноутбуке, ставится на экран как приложение. У каждого пользователя свой аккаунт, новые пользователи регистрируются по приглашению.

Адрес: **https://molitva.grishaweb.ru**

Устроено так же, как «Моя зачётка»: одна программа [PocketBase](https://pocketbase.io) (база данных, файлы, вход, панель администратора) плюс страницы приложения из папки `pb_public`.

```
pb_public/       интерфейс приложения (HTML, CSS, JS, шрифты, камень, значки)
pb_migrations/   структура базы и правила доступа
pb_hooks/        приглашения, первый администратор, лимит места, проверки разделов и стихов
deploy/          установка и обновление на сервере
```

## Установка на сервер

Приложение ставится на тот же сервер рядом с «Зачёткой». Общие настройки Caddy (файл `/etc/caddy/Caddyfile`) установка не меняет, «Зачётка» продолжает работать как раньше.

### Что нужно заранее

В Beget, в DNS домена `grishaweb.ru`, добавлена подзона `molitva` с A-записью `168.113.170.172`. После добавления подождите 15–60 минут.

### Установка одной командой

Подключитесь к серверу (`ssh root@168.113.170.172`) и выполните:

```
curl -fsSL https://raw.githubusercontent.com/Grisha-Kr/molitva/main/deploy/install.sh | bash -s -- molitva.grishaweb.ru me@grishakr.ru "Григорий Кривобок"
```

Скрипт сам:
- проверит, что в общем файле Caddy есть строка `import /etc/caddy/sites/*.caddy` (если её нет, остановится и объяснит, что делать);
- проверит, что адрес указывает на сервер;
- скачает код и PocketBase 0.40.3 в `/opt/molitva`;
- включит автозапуск (служба `molitva`, порт `127.0.0.1:8091`);
- положит файл сайта `/etc/caddy/sites/molitva.caddy` (только TLS 1.2), проверит настройки и перезагрузит Caddy;
- создаст вход в панель администратора и покажет пароль. Он же сохранится в `/opt/molitva/superuser.txt`.

### Первый вход

**Сразу после установки** откройте `https://molitva.grishaweb.ru` и создайте аккаунт. Первый зарегистрированный пользователь становится администратором; остальные смогут зарегистрироваться только по вашему приглашению.

## Приглашения

«Профиль» → «Приглашения». Укажите, для кого приглашение и сколько человек может по нему зарегистрироваться, нажмите «Создать и скопировать ссылку». Ссылку можно переслать в мессенджере: человек откроет её, и код подставится сам.

## Установка на телефон и ноутбук

- **iPhone** (Safari): откройте сайт → «Поделиться» → «На экран „Домой“».
- **Android** (Chrome): меню из трёх точек → «Установить приложение» или «Добавить на главный экран».
- **Ноутбук** (Chrome, Edge, Яндекс Браузер): значок установки в адресной строке справа.

## Обновление

Когда в репозитории появилась новая версия, подключитесь к серверу и выполните:

```
bash /opt/molitva/src/deploy/update.sh
```

Скрипт сохраняет копию базы в `/opt/molitva/pb_data/backups`, загружает новый код и перезапускает приложение. В конце он пишет «Готово: приложение обновлено и работает». При ошибке приложение запускается снова на старой версии.

Чтобы обновить сам PocketBase, поменяйте `PB_VERSION` в `deploy/install.sh` и запустите установку ещё раз с теми же параметрами. Перед этим прочитайте заметки к выпуску: до версии 1.0 в PocketBase бывают несовместимые изменения.

## Где настройки

Файл `/opt/molitva/molitva.env`:
- `APP_URL` — адрес приложения (нужен для писем восстановления пароля);
- `OWNER_NAME`, `CONTACT_EMAIL` — данные оператора для политики конфиденциальности;
- `USER_QUOTA_MB` — сколько мегабайт фото и файлов можно хранить одному пользователю (по умолчанию 500);
- `BEHIND_PROXY=1` — приложение стоит за Caddy.

После правки выполните `systemctl restart molitva`.

Панель администратора PocketBase: `https://molitva.grishaweb.ru/_/` (почта и пароль в `/opt/molitva/superuser.txt`).

## Резервные копии

- Сервер сам делает копию базы каждый день в 3:00 и хранит 14 последних. Скачать или восстановить: панель `/_/` → «Settings» (настройки) → «Backups» (резервные копии).
- Хостинг делает еженедельную копию всего сервера.
- Скачивание копии из самого приложения появится на этапе 3. До этого иногда скачивайте копию из панели `/_/`.

## Почта для восстановления пароля (этап 3)

Пока почта не настроена, кнопка «Забыли пароль?» письмо не отправит. Настройка такая же, как в «Зачётке»: панель `/_/` → «Settings» → «Mail settings» (почта), SMTP Яндекса (`smtp.yandex.ru`, порт 465) или Beget с паролем приложения.

## Если что-то не работает

```
systemctl status molitva           # работает ли приложение
journalctl -u molitva -n 50        # последние сообщения и ошибки
systemctl restart molitva          # перезапуск
systemctl status caddy             # работает ли Caddy (https и адреса)
journalctl -u caddy -n 50          # ошибки получения сертификата
```

## Персональные данные

Приложение хранит почту, имя, записи, фото и файлы пользователей на сервере в России. При регистрации пользователь даёт согласие на обработку данных, страница политики: `/privacy.html`. Каждый видит только свои записи; записи молитв и файлы закрыты и останутся закрытыми, когда появятся группы.

## Разработка у себя на компьютере

```
./pocketbase serve --http 127.0.0.1:8091 --dir /tmp/molitva --publicDir pb_public --hooksDir pb_hooks --migrationsDir pb_migrations
```

Приложение откроется на `http://127.0.0.1:8091`, панель на `http://127.0.0.1:8091/_/`.
